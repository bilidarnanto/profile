Panduan: Tahapan Agar Profil Terindex Google

Teknis di sisi repo sudah beres. Sisa langkah di bawah ini butuh akun Google pemilik situs.

https://bilidarnanto.github.io/profile/

Yang sudah diselesaikan di repo

  • robots.txt menunjuk sitemap ke alamat benar (/profile/sitemap.xml) — sebelumnya ke alamat domain induk yang 404, inilah sebab utama halaman tidak pernah ditemukan Google.
  • sitemap.xml mencantumkan URL kanonik yang sebenarnya plus tanggal lastmod.
  • Canonical tag di halaman utama mencegah Google bingung antara /profile/ dan /profile/index.html.
  • Structured data (JSON-LD): Person, ProfilePage, dan daftar publikasi — bahan untuk knowledge panel saat nama dicari.
  • Judul & deskripsi memuat kata kunci nyata: Mechanical Engineer, ANZSCO 233512, IoT, energi terbarukan, BNC/GNP, NACA 4712.
  • Open Graph + Twitter Card dan gambar preview 1200×630 agar rapi saat link dibagikan (ini juga memancing orang menautkan halaman).
  • Menu anchor & id per bagian (#sol, #research, #experience, #skills, #education) sehingga struktur halaman terbaca crawler.
  • Atribut bahasa pada 158 elemen bilingual, dan halaman 404 diberi noindex.

Langkah yang perlu Anda jalankan

1 Verifikasi kepemilikan di Google Search Console

Sekali saja · ±5 menit
Wajib
  • Buka search.google.com/search-console → Add property.
  • Pilih jenis URL prefix (bukan Domain, karena Domain butuh akses DNS), lalu isi: https://bilidarnanto.github.io/profile/
  • Pilih metode verifikasi HTML tag, copy kode <meta name="google-site-verification" ...> yang muncul.
  • Tempel kode itu di index.html, tepat di baris komentar <!-- Verification: ... --> di dalam <head>, lalu commit & push.
  • Tunggu 1–2 menit agar GitHub Pages selesai build, lalu klik Verify.

Kirim kode verifikasinya ke saya bila ingin saya pasang langsung — penanda tempatnya sudah saya siapkan.

2 Submit sitemap

Setelah properti terverifikasi
Kunci
  • Menu Sitemaps → isi kolom dengan sitemap.xml (cukup nama filenya) → Submit.
  • Status harus Success dengan Discovered URLs: 1. Kalau Couldn't fetch, cek dulu alamat https://bilidarnanto.github.io/profile/sitemap.xml di browser (saat ini statusnya sudah normal).
  • Ini memberi tahu Google alamat halaman secara eksplisit — tanpa ini halaman baru di subfolder sulit ditemukan.

3 Minta indexing halaman utama

Setelah sitemap tersubmit
±1 menit
  • Menu URL Inspection → tempel https://bilidarnanto.github.io/profile/ → Enter.
  • Klik Request indexing. Status awal biasanya URL is on Google belum muncul, itu wajar.
  • Lakukan sekali saja. Mengulang berkali-kali tidak mempercepat, hanya membuang kuota harian.

4 Bangun backlink (faktor terbesar setelah submit)

Dikerjakan bertahap
Prioritas
  • Buat repo bilidarnanto/bilidarnanto (nama harus sama persis dengan username) berisi README.md dengan link ke profil. Repo ini tampil di halaman GitHub Anda dan sering dikunjungi crawler.
  • Pasang link yang sama di bio ResearchGate, LinkedIn, Google Scholar, dan tanda tangan email/WhatsApp.
  • Satu backlink dari profil yang memang relevan lebih bernilai daripada banyak tautan acak.

5 Tambah halaman agar ada lebih banyak pintu masuk

Opsional tapi berdampak
Jangka panjang
  • Satu URL memang bisa terindeks, tetapi pecah isi menjadi halaman terpisah (mis. riset BNC/GNP, turbin angin NACA 4712, SolarMBG IoT) membuat lebih banyak kata kunci punya halaman sendiri.
  • Setiap halaman baru: judul unik, <link rel="canonical"> sendiri, dan tambahkan <url> baru di sitemap.xml lengkap dengan <lastmod>.
  • Perbarui konten berkala — Google memprioritaskan halaman yang diperbarui.

6 Pantau status indexing

Cek 1–2 minggu sekali
Rutin
  • Search Console → Indexing › Pages: lihat apakah URL berstatus Indexed.
  • Search Console → Performance: mulai terlihat query yang memunculkan halaman.
  • Cek manual di Google: ketik site:bilidarnanto.github.io/profile
  • Perkiraan waktu: 3 hari sampai 4 minggu. Jika lewat 6 minggu belum muncul, buka laporan Pages untuk membaca alasan persisnya (Crawled – currently not indexed atau Discovered – currently not indexed) dan kirimkan ke saya.

7 Opsional: Bing & mesin pencari lain

Tambahan · ±3 menit
Opsional
  • Buka Bing Webmaster Tools → pilih Import from Google Search Console agar tidak perlu verifikasi ulang.

Ekspektasi waktu & hal yang justru merugikan

TahapPerkiraan hasil
Setelah submit sitemapGoogle mulai meng-crawl dalam hitungan jam–2 hari
Setelah Request indexingAntrean crawl, biasanya 1–7 hari
Muncul di hasil pencarianUmumnya 1–4 minggu setelah crawl
Muncul untuk pencarian nama lengkapLebih cepat, terutama setelah backlink dari profil resmi

Hindari

Justru bisa menurunkan kepercayaan Google
  • Membeli backlink atau menukar tautan massal.
  • Menekan Request indexing berulang kali setiap hari.
  • Menduplikasi isi halaman di beberapa URL tanpa canonical.
  • Menumpuk kata kunci di deskripsi atau judul.

Checklist cepat

  • Property /profile/ terverifikasi di Search Console
  • sitemap.xml tersubmit dengan status Success
  • Halaman utama sudah di-Request indexing
  • Repo bilidarnanto/bilidarnanto berisi link ke profil
  • Link dipasang di ResearchGate / LinkedIn / email
  • Dicek berkala lewat site:bilidarnanto.github.io/profile
